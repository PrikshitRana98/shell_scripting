# Shell Scripting for DevOps — 7 Day Plan

## Day 1 — Linux & Bash Basics

* Shell vs Bash
* Terminal & Shell
* Basic Linux commands
* `pwd`, `ls`, `cd`, `mkdir`, `touch`, `cp`, `mv`, `rm`
* Create `.sh` files
* Shebang `#!/bin/bash`
* `echo`
* Comments
* `chmod` & file permissions
* Exit codes `$?`
* **Project:** `system_info.sh`

## Day 2 — Variables & Conditions

* Variables
* `$variable` & `${variable}`
* Command substitution `$(command)`
* `read` / user input
* Environment variables
* `export`
* Script arguments: `$0`, `$1`, `$2`, `$#`, `$@`
* `if`, `elif`, `else`
* Numeric & string comparisons
* File conditions: `-f`, `-d`, `-e`
* **Project:** `environment_check.sh`

## Day 3 — Loops & Functions

* `for` loop
* `while` loop
* `until`
* `break` / `continue`
* `case`
* Functions
* Function arguments
* `return`
* **Project:** `service_manager.sh`

## Day 4 — Text Processing & Logs

* Pipes `|`
* Redirection `>`, `>>`, `2>`, `2>&1`
* `grep`
* `awk`
* `sed`
* `cut`
* `sort`
* `uniq`
* `wc`
* `find`
* Log analysis
* **Project:** `log_analyzer.sh`

## Day 5 — Linux Server Management

* Processes: `ps`, `top`, `htop`, `pgrep`, `kill`
* Background processes
* CPU monitoring
* Memory: `free`
* Disk: `df`, `du`
* Services: `systemctl`
* Logs: `journalctl`
* Networking: `ping`, `curl`, `wget`, `ss`, `ip`, `dig`
* **Project:** `server_monitor.sh`

## Day 6 — Production Bash & Automation

* `set -euo pipefail`
* Error handling
* Exit codes
* Debugging: `bash -x`
* Logging
* `trap`
* `mktemp`
* Cron jobs
* Environment configuration
* Secrets handling
* **Project:** `backup.sh`

## Day 7 — Shell + DevOps

* Git automation
* Docker automation
* Terraform automation
* Azure CLI
* CI/CD
* GitHub Actions
* Shell scripts in pipelines
* **Final Project:** `devops-deploy.sh`

### Final Goal

Linux → Bash → Automation → Git → Docker → Terraform → Azure → CI/CD
